## Checked, clean

- **QML Process usage:** every `Process`/`execDetached` takes an argv list. `[svc.bin].concat(args)` with fixed subcommand literals; user data only after the verb: `mode put NAME --data JSON`, `clip get ID`, `clip list --query Q` (value of `--query`, a flag with a fixed name, never positional), `mode show/rm/save NAME`, `deck unpair NAME`. Names are charset-validated in Rust (`valid_name`, deck `config.rs`). No `sh -c`, no string-built command, no `eval`/`Function`/`Qt.createQmlObject` on config values (grep). `Qt.openUrlExternally` only with two constant GitHub URLs.
- **Clipboard/phone text:** clip list, preview (`TextArea` PlainText), transfers, phone settings, settings pages use `textFormat: Text.PlainText`; `TextEdit` defaults to PlainText; deck pair payload is stance-generated and single-quoted into the copied test command (cannot contain `'`); preview capped at 64k chars. `contrib/fake-clip.sh` fixture includes `<b>plain</b>` as a check.
- **IPC:** `qs ipc` targets `stance` (toggle, open, close, settings, clip, clipOpen, clipClose, confirm, revert) and `stanceclip` (toggle, open, close). No string arguments, no data returned. Any process of the same user can already run `stance confirm`/`revert`, so no escalation; the socket lives in the user runtime dir. Worst case is opening the clip shelf on screen (shoulder surfing).
- **panel.json:** parsed with JSON.parse in try/catch, `normPrefs` whitelists board ids/sizes and normalises theme overrides; newer schema or unreadable file is never rewritten (fail closed, covered by qml-smoke). i18n lang validated, files loaded read-only, missing keys return the key.
- **systemd units:** absolute `ExecStart`, `Restart` with `RestartSec`, `PartOf=graphical-session.target`; clip units do not store anything until enabled; no `User=`, no `EnvironmentFile`, no secrets in unit files. `sed` in flake only rewrites known prefixes.
- **PKGBUILD:** `cargo fetch --locked` / `--frozen`, `check()` runs the unit tests, `install -Dm` modes right (units 644, binary 755), `-git` conflicts/provides symmetrical, `sha256sums=SKIP` only for the git source, depends/optdepends cover every external tool the README lists (hyprland, quickshell, ddcutil, brightnessctl, wpctl/pw-dump, hyprsunset, power-profiles-daemon, notify-send, adb, wl-clipboard).
- **CI:** no `${{ }}` inside `run:` (only `secrets.GITHUB_TOKEN` in `with`/`env`); no `pull_request_target`; release `build` job is read-only, only `publish` has `contents: write`; tag/Cargo.toml mismatch aborts; tag name reaches shell only as env var; `qml-smoke` runs the tests as a non-root `runner` user; dependabot covers github-actions and cargo.
- **Test isolation:** `qml-smoke.sh`, `fake.sh`, `upgrade.sh`: `mktemp -d` 0700, own `XDG_*`, `STANCE_BACKEND=fake`, `WAYLAND_DISPLAY`/`HYPRLAND_INSTANCE_SIGNATURE` unset (smoke); trap removes the workdir. `nested.sh`: own config/state/deck/clip dirs, only hyprsunset processes whose environ carries the nested signature are killed, no `pkill`, no systemctl, every clipboard action goes through the nested `WAYLAND_DISPLAY`. `qml-smoke.sh` ran green here without touching `~/.config`.
- **end4 integration:** `stance setup` only prints steps (no files written); docs give the two symlinks plus one QML line and the removal is "delete the line and the two links", i.e. fully reversible and nothing in the user's shell config is overwritten, so no backup is needed. `StanceClipShelf` is one instance (IPC target once), `StanceUtilButton` one per screen as documented.
- **Docs vs behaviour:** README ipc names (`ipc call stance clip`, `stanceclip toggle`), install file lists, units list, `fake-stance.sh` "never calls systemctl", clip "stores nothing until enabled" and "private but not encrypted" all match code. The one gap is S1 (EDID "only displayed").
- **Other:** `examples/` TOML carries no command fields; Waybar block uses fixed commands; issue template asks for `doctor --report` (secret-free per prior scans); `Qt.resolvedUrl` i18n path decoding fixed in 0.8.0.
