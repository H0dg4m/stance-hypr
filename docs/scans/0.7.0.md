**Range:** `4aab717..eec0c94` (previous scan docs/scans/0.6.0.md). **Scope:** incremental; the diff (13 files, +2481 lines: transfer.rs, link.rs, stream.rs, net.rs, client.rs, main.rs, tests) is the whole new attack surface; older code not rescanned.
